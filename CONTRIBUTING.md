# Contribuição

1. Crie uma branch `feature/`, `fix/`, `docs/` ou `hotfix/` a partir de `main`.
2. Faça commits pequenos e claros; não inclua segredos, arquivos `.env`, dependências instaladas ou dados pessoais.
3. Execute `cd backend && npm test` e registre o resultado.
4. Abra um pull request para `main`, preencha `.github/PULL_REQUEST_TEMPLATE.md` e solicite revisão do par autorizado.
5. Aguarde CI verde e aprovação antes do merge. Push direto e force-push em `main` não fazem parte do fluxo permitido.
6. Após merge, registre a baseline pelo SHA; releases formais devem usar tags SemVer.

Consulte [`docs/PLANO_GCS.md`](docs/PLANO_GCS.md) para as regras completas de configuração, acesso, ambientes e evidências.
